# Social Network & Direct Messaging System 🚀

A full-stack responsive web application for real-time messaging, group chats, status/stories, and QR code friend requests built using PHP and MySQL.

## ✨ Features
- 💬 Real-time Direct & Group Messaging
- 📱 100% Mobile Responsive UI
- 📸 24-Hour Stories / Status Updates
- 📷 Back-Camera QR Code Scanning for adding friends
- 🎙️ Voice Notes & File Sharing
- 🔔 Live Notifications & Online Status Heartbeat
- 🔑 User Authentication & Secure Session Management

## 🛠️ Tech Stack
- **Backend:** PHP (Procedural with Prepared Statements)
- **Database:** MySQL
- **Frontend:** HTML5, CSS3 (Flexbox/Media Queries), JavaScript (Fetch API)
- **Libraries:** HTML5-QRCode Scanner
